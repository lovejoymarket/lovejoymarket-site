# LoveJoy Market Website

Custom-coded website for LoveJoy Market.

## Planned public navigation

1. Home
2. Tattoos
3. Events
4. Market
5. About

## Architecture

- Static HTML/CSS/JavaScript for a lightweight first release
- Content separated into `/data` files where practical
- Square will remain the system for appointments, checkout, payments, and event transactions
- The public website will be hosted independently and connected to `lovejoymarket.co`

## Build order

Home → Tattoos → Events → Market → About → Footer/private operations entry → QA/publish

## Current status

Initial repository scaffold only. Page copy and final layout will be developed section-by-section.

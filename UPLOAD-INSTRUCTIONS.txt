LOVEJOY MARKET | POP-UPS WEBSITE UPDATE | SEPTEMBER 22, 2026
===========================================================

These files are meant to be uploaded into the ROOT of your existing
GitHub repository: lovejoymarket/lovejoymarket-site, main branch.
Use Add file > Upload files, drag in the contents of this ZIP, and commit.
GitHub's web uploader does not accept a ZIP as an automatic website update:
unzip this file first, then upload the FILES inside.

Upload the changed HTML, JSON, XML, CSS, and site.js files.
Do NOT delete your existing other site files, logos, gallery, photos, or fonts.

WHAT CHANGED
- Added popups.html and popups.css.
- Replaced Events links with Pop-Ups links throughout the existing HTML pages.
- Removed the old October event tiles, dated collaborator options, and calendar UI.
- Removed the Super Secret Soft Opening banner, deal card, and JS inquiry logic.

404, etc.) not in the last full-site ZIP, those existing pages are intentionally
